# Dotfiles - Arch Linux + Hyprland (Lua)

Configuração focada em máxima velocidade, baixa latência e consumo mínimo de recursos no Arch Linux nativo em Wayland.

## Stack
- **Compositor:** Hyprland (Configuração oficial em Lua 5.4)
- **Barra de Status:** Waybar (Orientada a eventos)
- **Bloqueio de Tela:** Hyprlock
- **Lançador & Menus:** Fuzzel
- **Terminal:** Foot
- **Notificações:** Mako

## Principais Atalhos
- `SUPER + Return`: Terminal Foot
- `SUPER + D`: Lançador de aplicativos (Fuzzel)
- `SUPER + C`: Fechar janela
- `SUPER + L`: Bloquear tela (Hyprlock)
- `SUPER + Escape`: Menu de encerramento da sessão
- `SUPER + T`: Workspace de Terminal
- `SUPER + A`: Workspace de Agenda
- `SUPER + ALT + E`: Workspace de E-mail
- `SUPER + F`: Workspace de Arquivos
- `SUPER + B`: Ocultar / Mostrar Waybar (Modo Foco)
- `Print`: Capturar área para a área de transferência
